### Hi there, I'm Ruban K 👋

I'm an astrophysicist at [IIST Thiruvananthapuram](https://www.iist.ac.in/), working on timing and spectral studies of **neutron star X-ray binaries** using AstroSat. I'm interested in making astrophysics research more open, reproducible, and well-documented.

- Some projects and analyses I work on:
  - [astrosat-laxpc-burst-analysis](https://github.com/rubankraj/astrosat-laxpc-burst-analysis): Timing and spectral analysis of Type-I X-ray bursts using AstroSat/LAXPC
  - Variable star characterization in open cluster IC 4756 using Gaia, Kepler, and TESS
  - FITS data cube visualization and radio interferometric imaging using CARTA and CASA

- Tools and languages I use:
  - Python (Astropy, NumPy, Matplotlib), HEASoft, XSPEC, SAOImage DS9, CASA, CARTA
  - LaTeX, Linux, Git, VS Code
